Configure Db2 instance

You can add Db2 hosts and Db2 database instances to RSC so that RSC can discover and protect the databases that belong to each instance.

A Db2 instance is the logical Db2 environment on a host that manages a group of Db2 databases. Configuring a Db2 instance in RSC involves the following tasks:

  1. Adding a Db2 host: You add the Db2 host to a Rubrik cluster and install Rubrik Backup Service (RBS).
  2. Adding a Db2 database instance: You add the Db2 database instance to RSC by providing the instance name, the IP addresses or hostnames of the participating hosts, the instance owner, and the password.

What RSC does after you add the instance

After you add the instance, RSC connects to the instance and retrieves the Fully Qualified Domain Name, the Db2 version, and installation path. RSC then reads the db2nodes.cfg file to determine whether the instance is standalone, partitioned (DPF), or part of a pureScale cluster. RSC then discovers the databases on the instance, validates the required configuration parameters such as TRACKMOD, LOGARCHMETH1, LOGARCHMETH2, and LOGARCHOPT1, and retrieves the UTC offset from the host. Discovery runs every 15 minutes to detect new databases and configuration changes.
