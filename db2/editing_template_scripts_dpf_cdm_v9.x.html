Editing template scripts for DPF environment

After creating a template script, edit the script to customize and ensure accuracy of the recovery procedure for the target Db2 database in CDM version 9.x.

Procedure

  1. Log in to the target Db2 host as an instance user.
    At the prompt, enter:
    su - db2instancename

    Where db2instancename is the name of the instance where the target database is restored.

  2. Modify the generated redirect scripts to use them for restoring to the target database.
    The redirect generate script <scriptName>_<partitionNumber>.clp generates a script, and the database administrators must modify this script. These changes can be, but are not limited to, changing the directory where the table spaces and database storage paths are created as part of the restore.

Results

You can now use the edited template script to perform a restore operation.

What to do next

Use the modified script to perform the restore, as described in Using template scripts for DPF environment.
