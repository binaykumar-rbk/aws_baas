          • Creating a custom SLA Domain

            Create a custom SLA Domain to define and customize workload protection and management policies.

          • Creating SLA Domains for many-to-one replication

            Create an SLA Domain for many-to-one replication, the traditional replication mode supported by RSC SLA Domains. This method consolidates data protection from multiple source clusters onto a single target cluster, ensuring centralized recovery and protection.

          • Creating SLA Domains for one-to-one replication

            Create an SLA Domain for one-to-one replication when there are more than two replication targets and the source and replication clusters are in a dedicated replication configuration. With one-to-one replication, you can configure multiple replication pairs, but a source cluster can replicate to a maximum of two target clusters.

Assigning an SLA Domain to Proxmox virtual machines

Assign an SLA Domain to protect Proxmox virtual machines and define their backup frequency and their retention policies.

About this task

You can assign an SLA Domain to one or more Proxmox virtual machines in RSC.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, click Inventory.
    The Inventory page appears.
  4. Click the Proxmox VE inventory card.
    The Proxmox VMs page appears.
  5. Select a Proxmox virtual machine.
    The virtual machine details page appears.
  6. Select the Proxmox virtual machine instances to protect and click Manage Protection.
    The Manage Protection wizard appears.
  7. Select an SLA Domain to protect the instances or add a new SLA Domain by clicking .
    For instructions on how to create a custom SLA Domain, see the RSC documentation on creating a custom SLA domain.
  8. Select a protection option:
    OptionDescription
    Don't protect Excludes Proxmox instance from all further SLA Domain protection.
    Clear current SLA Domain Removes the existing SLA Domain assignment from the Proxmox instance. Selected objects now inherit the SLA Domain of the next higher-level object.
  9. Click Next.
    The confirmation page appears.
  10. Click Assign.

Results

RSC assigns the selected SLA Domain to the Proxmox virtual machines.
