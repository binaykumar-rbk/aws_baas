Uses for secure port 443 TCP

Each Rubrik cluster requires that you open an outbound connection through TCP port 443 for secure transmission while accessing specific sites.

A cluster requires an outbound connection through TCP port 443 to access specific sites. Each node in the cluster requires that your network firewalls and security devices allow these connections. You can use a proxy server for communication if required.
