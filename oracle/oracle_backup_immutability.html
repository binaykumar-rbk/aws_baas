Oracle backup immutability

When you archive Oracle backup data to an archival location with an immutability policy, RSC automatically protects Oracle database snapshot and log backup files with object-level locks that prevent deletion for the duration of the retention period.

Cloud storage providers support immutability policies that lock objects against deletion for a defined period. When RSC uploads database backups to an archival location that uses one of these policies, it applies a lock to the database snapshot and log backup files at the storage layer. These locks protect the backups against ransomware attacks and accidental deletion, and help meet compliance requirements.

How locks are applied and maintained

RSC automatically applies locks when it uploads backups to an immutable archival location.

For database backups, the database snapshot retention period that the SLA Domain specifies for the archival location determines the lock duration.

For log backups, RSC extends each lock every 24 hours for as long as the log backup is within the configured SLA Domain log retention period.

The log retention period that the SLA Domain specifies for the archival location determines the lock duration. If the SLA Domain specifies no log retention period, RSC uses the database snapshot retention period for that archival location.

Reduce the SLA log retention period

If you reduce the log retention period in the SLA Domain for an existing workload, RSC applies the reduced retention period to new log backups immediately and releases existing locked log backups only when the lock expires.

Lock expiration can take up to 28 days.

Important:
RSC processes database log backups at an archival location as a sequential recovery chain. If a locked log backup is pending release, RSC cannot delete subsequent log backups in the chain until the lock expires. If archival storage costs are a concern, Rubrik recommends planning SLA Domain log retention changes accordingly.

Enable data immutability

Oracle workloads receive backup immutability protection when they are assigned an SLA Domain with an archival policy that routes data to an archival location configured for immutability. For more information about cloud storage providers that support immutability, see Archival locations.
