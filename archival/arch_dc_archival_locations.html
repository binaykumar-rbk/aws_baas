    • Data center archival locations

      RSC supports archiving backed-up data from data center workloads to external storage destinations, including cloud storage providers, NFS shares, S3-compatible object stores, and tape.

      • Introduction to archiving

        Archiving enables you to copy backup data from a Rubrik cluster to a cost-efficient, long-term storage location, freeing up primary cluster capacity while retaining recovery capability.

      • High-level workflow for archiving

        The archiving workflow consists of six high-level phases, starting from planning to recovery.

      • Plan your archiving setup

        Before creating an archival location, evaluate your storage provider options, cost model, security requirements, and network capacity to ensure a successful deployment.

      • Configure archival locations

        Configure a data center archival location for your chosen storage provider. Each provider has specific preparation steps and configuration requirements.

      • Protect data in archival locations

        Use SLA Domain archival policies to configure how data center workloads are archived to your archival locations, and monitor archival jobs to ensure data is protected as expected.

      • Monitor data center archival locations

        RSC provides visibility into the status, storage consumption, throughput, and job activity of your data center archival locations.

      • Manage data center archival locations

        RSC provides management options to update, pause, disable, delete, or change the ownership of a data center archival location after it has been created.

      • Recover data from archival locations

        You can recover data from an archival location when the primary Rubrik cluster is unavailable or when archived snapshots are needed for restore operations.

      • Migrate data center archival locations

        Manage archival data mobility scenarios including cloud provider migrations, cluster retirements, and moving archives between Rubrik clusters.

      • Older CDM functionality

        This section covers archival features available in Rubrik CDM versions earlier than 9.4.0-p1, including bucket-level and container-level immutability for S3 and Azure archival locations.

      • Troubleshooting data center archiving issues

        You can diagnose and resolve common archival issues, including error codes, connectivity failures, performance problems, and immutability compliance issues.

    • Rubrik Cloud Vault

      Rubrik Cloud Vault is a Rubrik-managed cloud service that provides isolated and immutable copies of protected data, enhancing cyber resiliency.

    • Cascading archival

      Using cascading archival, you can increase replicated data redundancy and decrease data storage costs by archiving replicated snapshots from a replication target Rubrik cluster to a remote archival location.

    • Replication

      The replication feature directs the Rubrik cluster to send replicas of source snapshots or backups to a target Rubrik cluster and defines the maximum time to keep the replica on each cluster.
