Rubrik cluster owner role

Owner Rubrik clusters can pause, disable, and delete archival locations. The actions available on a location vary depending on its current state.

Owner cluster controls

Rubrik clusters with the owner role allow you to pause, disable, and delete archival locations.

Control Description
Pause Pausing an archival location:
  • Prevents the owner Rubrik cluster from starting new archiving operations on the archival location
  • Cancels the running archiving operations when possible
  • Continues running archiving operations to conclusion when they cannot be canceled gracefully
  • Allows read operations
  • Allows expiration of existing snapshots in the archival location
Disable Disabling an archival location leads to the same behavior as pausing the archival location.

In addition, disabling the location prevents all modification operations on the archival location.
Delete

Deleting an archival location removes the association between the Rubrik cluster and the archival location. After an archival location is deleted from a cluster, the cluster loses visibility of the snapshots in that archival location.

Note:
To delete an archival location from the owner cluster, you must first disable it. You do not need to disable the archival location before deleting it from a reader cluster.

Actions allowed on archival locations

The actions that you can perform through an archival location vary depending on the state of the archival location.

Archival location state Upload snapshots Download snapshots Expire and delete snapshots SLA Domain mapping
Paused No Yes Yes Yes
Disabled No Yes No Yes
Deleted No No No No
