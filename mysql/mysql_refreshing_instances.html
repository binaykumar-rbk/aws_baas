Refreshing MySQL instances

To ensure that the information on a Rubrik cluster is up to date and accurate, refresh the MySQL instance. When you refresh a MySQL database instance, all databases local to the selected instance are discovered and the relevant metadata is updated.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, click Inventory.
    The Inventory page appears.
  4. Click the MySQL inventory card.
    The MySQL page appears.
  5. Click for the instance you want to refresh and select Refresh Instance.
    The instance takes a few minutes to refresh.

Results

The MySQL database instance is refreshed. RSC discovers all the databases local to the selected instance and updates the relevant metadata.
