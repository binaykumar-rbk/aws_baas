Restoring Gmail data for multiple users

Restore Gmail, Calendar, and Contacts data for multiple users simultaneously from a point-in-time snapshot using mass recovery.

Before you begin

Ensure that the following prerequisites are met:
  • You have a valid snapshot for each user you want to restore.
  • Your RSC account has a role that includes the Recovery to Origin permission.
  • Your RSC account has the mass recovery license.

Procedure

  1. Log in to RSC.
  2. Click and select SaaS App Protection.
    The SaaS Apps dashboard appears.
  3. Click the Google Workspace card and click View Details on the Gmail, Calendar, and Contacts inventory.
  4. On the Restore Users card, click Get Started.
    The restore wizard appears, displaying an overview of the restore process.
  5. Review the steps and click Next.
    The Select the Recovery Scope page appears.
  6. Select All Gmail, Calendar, and Contacts data of multiple users and click Next.
    The Select Users and Recovery Point page appears.
  7. Select the user and the corresponding snapshot you want to restore.
    You can filter the list of users by Organizational Unit or Status, such as Active or Relic. You can search the list of users by username.
    Note:
    RSC selects the most recent snapshot by default. You can select a different snapshot for each user, as described in Changing a snapshot for Gmail.
    The Select a Restore Location page appears.
  8. Select Restore to the original user.
    RSC restores Calendar events to the original calendar with a pre-filled label. RSC restores emails and contacts to their original labels and you can add a new label.
  9. Click Next.
  10. Review the summary on the Confirmation page and click Restore.
    Note:
    Mass recovery is an in-place operation and data is always restored to the original user accounts.

Results

You have successfully initiated the mass recovery job. You can monitor the progress on the Events page.

What to do next

Verify that the restored data appears in the destination user accounts.
