Installing RBS on AIX hosts

Install RBS software on AIX hosts.

Before you begin

Copy the most up-to-date AIX version of RBS to a temporary location that is available to the AIX operating system.

About this task

This task describes how to install RBS from the command line. You can also install RBS on multiple hosts using automation software, such as Puppet or Chef.

Procedure

  1. Open a terminal session on the host.
  2. Change the working directory to the location of the RBS software package.
  3. To install RBS, run the rpm package manager command.
    If sudo access is unavailable, log in as root to run the package manager command.
    sudo rpm -i rubrik-agent-aix.pcc.rpm

Results

The package manager installs RBS on the AIX host.

What to do next

Add the hosts that are running RBS to the Rubrik cluster.
