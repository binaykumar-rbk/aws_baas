Unmounting an AHV virtual disk

Unmount a live mounted AHV virtual disk from a Rubrik cluster.

About this task

The Rubrik cluster automatically unmounts the virtual disks whose data sources are migrated after the Mount Virtual Disks operation. The option to unmount is available only for those virtual disks whose data source has not been migrated.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, click Live Mounts.
  4. Click Nutanix Virtual Machine.
    A list of the mounted virtual machines and virtual disks appears.
  5. Open the ellipsis menu for a mounted virtual disk, and then select Unmount.
    The Unmount dialog box appears.
  6. Click Unmount.

Results

RSC removes the metadata associated with the selected virtual disks and removes the entry for the virtual disk from the Live Mounts page.

This action does not remove data protection objects and does not unmount the recovered and migrated virtual disks.
