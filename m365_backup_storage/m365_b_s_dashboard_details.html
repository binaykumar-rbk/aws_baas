      • Managing protection for SaaS applications

        Protect SaaS applications, such as Atlassian Jira and Salesforce, by assigning them to an SLA Domain. This protects the instance by applying backup frequency and retention policies.

      • Creating an SLA Domain for SaaS applications

        Create an SLA Domain with custom backup frequency and retention policies to retain snapshot data beyond a year.

      • Deleting an SLA Domain for SaaS applications

        Delete an SLA Domain you created for SaaS applications from RSC when it is no longer needed.

Microsoft 365 Backup Storage dashboard details

Information about the tabs available on the dashboards specific to Microsoft 365 applications protected using Microsoft 365 Backup Storage.

The following table provides details about the tabs available on the dashboards for Microsoft 365 applications (SharePoint sites, OneDrive user accounts, and Exchange mailboxes) protected using Microsoft 365 Backup Storage:
Tab Description
Monitor

Provides information on object recovery status and consumed licenses.

You can access the dashboard specific to each Microsoft 365 applications to view recovery status and use the Manage Protection link to assign the SLA Domain predefined by Microsoft.
Restore Provides an option to restore data associated with Microsoft 365 applications to mitigate data loss events such as accidental deletion, ransomware attacks, or other unforeseen incidents.
Manage Protection Provides an option to manage the SLA Domain assignment associated with Microsoft 365 applications.

From this tab, you can assign the SLA Domain predefined by Microsoft to protect Microsoft 365 applications and the associated objects.
