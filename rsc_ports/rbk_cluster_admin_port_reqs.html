Rubrik cluster administration port requirements

Port requirements for Rubrik clusters onboarded to RSC, covering cluster administration access, infrastructure services, notifications, monitoring, authentication, physical appliance, internode communication, and RSC connectivity.

When a Rubrik cluster is onboarded to RSC, the cluster requires additional ports for administration, infrastructure services, and notifications. These ports apply to the CDM cluster. They are separate from the workload protection ports described in the other topics and from ports used by RSC itself.

The following sections list the required ports by function. For the complete and authoritative list of all cluster ports, see Port specifications: Rubrik Security Cloud - Offline Recovery guide.

Cluster administration access

The following inbound ports on the Rubrik cluster provide SSH and web UI access for administration tasks.

Port/Protocol Source Destination Description
22 TCP Local client Rubrik cluster Enables administrator access to the Rubrik cluster CLI for support and administration tasks.
80 TCP Web UI client Rubrik cluster Redirects web UI clients to HTTPS.
443 TCP Web UI client Rubrik cluster Required for secure communication between web UI clients and the Rubrik cluster, and for REST API access.

For more information about managing Rubrik clusters in RSC, see Rubrik clusters.

Infrastructure services

The following outbound ports enable the Rubrik cluster to resolve hostnames and synchronize time with network infrastructure services.

Port/Protocol Source Destination Description
53 UDP Rubrik cluster DNS server Enables hostname resolution for the Rubrik cluster.
123 UDP Rubrik cluster NTP server Enables time synchronization with network time protocol servers. Also required between cluster nodes for peer time synchronization.

You can configure DNS and NTP servers directly from RSC. For more information, see Rubrik clusters.

Notifications

The following outbound ports enable the Rubrik cluster to send email alerts and system event notifications to external services.
Important:
You must open only the port that matches your email server configuration.
Port/Protocol Source Destination Description
25 TCP Rubrik cluster Email server Enables the Rubrik cluster to send email alerts. Required only if the email server uses this port.
465 TCP Rubrik cluster Email server Enables the Rubrik cluster to send email alerts using implicit TLS. Required only if the email server uses this port.
587 TCP Rubrik cluster Email server Enables the Rubrik cluster to send email alerts using SMTP with STARTTLS. Required only if the email server uses this port.
514 TCP Rubrik cluster Syslog server Enables the Rubrik cluster to send system event notifications to a remote syslog server.

Monitoring

The following ports enable Simple Network Management Protocol (SNMP) polling and trap forwarding for cluster monitoring. The SNMP daemon is off by default. These ports are required only when SNMP monitoring is enabled on the Rubrik cluster.

Port/Protocol Source Destination Description
161 UDP SNMP manager Rubrik cluster Required only when SNMP polling is enabled on the Rubrik cluster.
162 UDP Rubrik cluster SNMP trap receiver Required only when SNMP trap forwarding is configured on the Rubrik cluster.

Authentication

Important:

The following ports apply only if the Rubrik cluster is configured to use Active Directory or LDAP authentication. They are not required for RSC itself. RSC authenticates users through SAML 2.0 over standard HTTPS (port 443) and does not use LDAP or Active Directory directly. If the CDM cluster uses only local accounts, these ports are not required.

Port/Protocol Source Destination Description
88 TCP/UDP Rubrik cluster Active Directory server Permits Kerberos communication for SMB security.
389 TCP Rubrik cluster Active Directory or LDAP server Permits LDAP communication for directory services.
445 TCP Rubrik cluster Active Directory server Required for NTLM authentication.
464 TCP/UDP Rubrik cluster Active Directory server Permits Kerberos password set and change communication for SMB security.
636 TCP Rubrik cluster Active Directory or LDAP server Permits secure LDAP communication for directory services.
3268 TCP Rubrik cluster Active Directory Global Catalog Permits LDAP communication for SMB security across domains.
3269 TCP Rubrik cluster Active Directory Global Catalog Permits secure LDAP communication for SMB security across domains.

Physical appliance — out-of-band management

The following ports apply only to physical Rubrik appliances. They are not required for Software Defined Cluster (SDC), virtual, or cloud deployments. These ports terminate at the appliance Baseboard Management Controller (BMC), such as iLO or iDRAC, rather than at CDM software.

Port/Protocol Source Destination Description
623 UDP Administrator workstation Rubrik appliance BMC Enables Intelligent Platform Management Interface (IPMI) communication with the appliance BMC.
5900 TCP VNC client Rubrik appliance BMC Enables VNC console access through the appliance BMC.

Internode communication

By default, Rubrik clusters do not require customer firewall rules between cluster nodes. If your deployment places cluster nodes across firewalled network segments, such as VLAN-segmented node networks, contact Rubrik Support for the full internode port list.

RSC connectivity

The Rubrik cluster requires an outbound connection through port 443 TCP to communicate with RSC endpoints for cluster-to-RSC connectivity, support tunnel, cluster statistics, and error log uploads.

Port/Protocol Source Destination Description
443 TCP Rubrik cluster RSC endpoints Required for cluster-to-RSC connectivity, support tunnel, cluster statistics, and error log uploads. The specific endpoints that must be allowlisted depend on the CDM version. For more information, see Outbound connection through ports.
