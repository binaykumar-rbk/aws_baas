Enabling the Rubrik cluster to resolve the storage URL

Enable the Rubrik cluster to resolve the storage URL to the private IP address of the endpoint. This is required to use Rubrik Cloud Vault with a private endpoint.

Before you begin

Log in with a user account that has the CLI administrator role.

Procedure

  1. Using an administrator account, open an SSH session on the Rubrik cluster.
  2. Run the following command to configure the Rubrik cluster host file to map the private endpoint IP address to the public storage URL.
    network configure_ip_hosts_mapping
    Note:
    Use this command only when nodes are in the OK status.
  3. In the menu that appears, select the following options:
    • IP Address is the IP address of the private endpoint.
    • <storageaccountname>.blob.core.windows.net is the alias.
  4. Save and commit the mapping.

Results

The Rubrik cluster resolves the storage URL to the private IP address of the endpoint.
