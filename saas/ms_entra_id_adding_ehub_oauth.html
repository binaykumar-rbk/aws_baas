Adding Event Hub ingestion with OAuth

Add Event Hub log ingestion when adding a new Microsoft Entra ID directory to RSC with OAuth authentication.

Before you begin

For the required Azure resources, see Azure prerequisites for Event Hub log ingestion.

About this task

When you add a Microsoft Entra ID directory with OAuth and turn on Event Hub log ingestion, RSC provisions an event hub in your Azure subscription and streams Entra ID sign-in and audit logs into it. RSC generates the namespace and event hub name automatically.

Procedure

  1. Log in to RSC.
  2. Click and select Identity Resilience.
    The Identity Resilience dashboard appears.
  3. On the navigation bar, select Protection > Inventory > Microsoft Entra ID Inventory > Identity > Microsoft Entra ID.
    The inventory list for Microsoft Entra ID appears.
  4. Click Manage Directories.
    The Microsoft Entra ID page appears.
  5. Click Add Entra ID Domain.
    The Add an Entra ID Domain wizard appears.
  6. Select Protection to protect and recover directory and Intune objects, and then click Next.
  7. On the Domain Details page, select Configure with OAuth.
    With OAuth, RSC creates and configures the required Azure application and permissions automatically.
  8. In Entra ID Domain, enter the name for the Microsoft Entra ID domain.
  9. In Region, select the Azure region.
    RSC stores the Microsoft Entra ID snapshot data in this region.
    For GCC High tenants, only Azure Government regions are supported.
  10. Optional: Turn on Protect Intune Objects to include Intune objects in snapshots so you can recover them.
  11. Turn on Event Hub log ingestion to stream Entra ID sign-in and audit logs through an event hub.
    RSC provisions and configures an event hub in your subscription to receive Entra ID audit and sign-in logs. When this option is turned on, RSC prompts you to grant administrator consent a second time for the Event Hub ingestion application, in addition to the standard Entra ID directory application consent. For more information, see Event Hub log ingestion for Microsoft Entra ID.
  12. Under Access, select Full access.
  13. Click Next.
  14. Click Log in to Microsoft Entra ID with Global Administrator credentials.
    This grants RSC permission to access your Microsoft Entra ID data.
    The Microsoft Pick an account screen appears.
  15. Select a Microsoft account.
    When you authenticate to the Microsoft account, RSC displays the required permissions and requests your authorization.
    The Permissions requested screen appears.
  16. Click Accept.
  17. Click Log in to authorize ingestion.
    The Microsoft Pick an account screen appears.
  18. Select a Microsoft account.
    When you authenticate to the Microsoft account, RSC displays the required permissions and requests your authorization.
    The Permissions requested screen appears.
  19. Click Next.
  20. In Azure subscription, search for and select the subscription where RSC should create the event hub.
  21. In Azure region, select an Azure region.
  22. In Resource group name, enter a name for the resource group.
  23. In Event Hub namespace, enter the namespace name.
    You can find the namespace name in the Azure portal under Event Hubs.
  24. Click Add.

Results

RSC begins provisioning the Event Hub ingestion connection. After the first event arrives from the hub, ingestion moves to a streaming state and Entra ID sign-in and audit activity flows into RSC for identity threat detection.

What to do next

Optionally, you can view the progress on the Events page or create an SLA Domain to protect your Microsoft Entra ID directories.
