Required permissions for AWS outpost account

Information about the permissions that the outpost account requires to access the AWS account.

Important:
The following permissions are defined within the CloudFormation template that Rubrik deploys and are subject to resource conditions. Although the Access level may show Full access, indicating the use of a wildcard * for the service API, these actions are strictly scoped to resources that Rubrik creates and manages. Rubrik identifies the resources using prefixes like Rubrik* or lmnr*. This ensures Rubrik can only act on its own infrastructure within your AWS account.
The following table outlines the permissions that the outpost account requires to access the AWS account.
Permission Access level Use case
cloudformation:* Full access To manage CloudFormation stacks and stack sets for Rubrik resources.
lambda:* Full access To manage Lambda functions.
logs:* Full access To manage CloudWatch logs for Lambda functions.
s3:* Full access To manage S3 buckets and objects.
kms:* Full access To manage KMS keys for encryption.
secretsmanager:GetSecretValue Read To get secret values.
secretsmanager:DescribeSecret Read To describe secrets.
secretsmanager:List* List To list secrets.
secretsmanager:CreateSecret Write To create secrets.
secretsmanager:Update* Write To update secrets.
secretsmanager:Delete* Write To delete secrets.
secretsmanager:TagResource Write To tag secrets.
secretsmanager:UntagResource Write To untag secrets.
account:GetAccountInformation Read To read account metadata.
account:GetRegionOptStatus Read To read account metadata.
account:ListRegions List To list AWS regions.
iam:CreateServiceLinkedRole Write To allow creating service-linked roles.
sts:DecodeAuthorizationMessage Write To decode authorization messages for troubleshooting.
iam:CreateInstanceProfile Write To create instance profiles.
iam:DeleteInstanceProfile Write To delete instance profiles.
iam:AddRoleToInstanceProfile Write To add roles to Laminar instance profiles.
iam:RemoveRoleFromInstanceProfile Write To remove roles from instance profiles.
iam:PassRole Write To pass Rubrik Assumer role and Rubrik SaaS Lambda Execution role to Lambda and EC2.
iam:DetachRolePolicy Write To detach policies from Rubrik roles.
iam:DeletePolicy Write To delete Rubrik policies.
iam:DeleteRole Write To delete Rubrik roles.
cur:DescribeReportDefinitions Read To list cost and usage reports.
cur:* Full access To manage cost and usage reports.
ecr:GetAuthorizationToken Read To get ECR authorization token for Rubrik repositories.
ecr:BatchCheckLayerAvailability Read To check layer availability in Rubrik ECR repositories.
ecr:GetDownloadUrlForLayer Read To get download URLs for layers in Rubrik ECR repositories.
ecr:BatchGetImage Read To get images from Rubrik ECR repositories.
sts:AssumeRole Write To assume Rubrik Internal Write roles and Rubrik Internal roles.
sts:GetCallerIdentity Read To get caller identity.
secretsmanager:GetSecretValue Read To get secret values.
The following table describes the permissions required for using NAT gateway for the outpost account.
Permission Scope Use case
ec2:CreateNatGateway Write To create NAT gateways for outpost outbound internet connectivity.
ec2:DescribeNatGateways Read To list and monitor the status of existing NAT gateways used by the outpost.
ec2:DeleteNatGateway Write To delete NAT gateways when removing the outpost account.
