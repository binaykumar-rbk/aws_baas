Scheduling a Data Security Posture report

Create the schedule for a Data Security Posture report.

Procedure

  1. Log in to RSC.
  2. Click and select Data Security Posture.
    The Data Security Posture dashboard appears.
  3. Click Reports &Events.
  4. Select a report to view.
    Alternatively, in the Search report name field, enter a report name to search for a specific report.
    The selected report appears.
  5. Select an option for creating a schedule.
    OptionDescription
    If no schedule exists Click the dropdown next to Save and selectAdd schedule.
    If a schedule already exists Click the dropdown next toSave and select Schedules > Add New
    The Schedules window opens.
  6. Enter schedule details such as the name, time, and email addresses of the users to send the report to.
  7. Optional: In Email Content, deselect the Include charts in the email body option.
    This option is selected by default.
  8. In Attachments, select an option for attachments to the report.
    Without an attachment, the report will display the first 100 rows only. To see the full report, select either a CSV or PDF attachment option.
  9. Click Add.

Results

Data Security Posture creates a schedule for the selected report.
