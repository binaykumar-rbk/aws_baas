Resolving archival lag

RSC alerts you when archival lag builds up on a data center archival location and recommends prioritized actions. Use the Resolving Archival Lag dialog box to review and apply the recommendations that reduce lag before it affects backups and recovery.

Before you begin

You must have a data center archival location managed by a supported Rubrik cluster and a role that permits viewing and managing archival locations.

About this task

Archival lag is the total number of snapshots on a cluster waiting to be archived. This count increases during active backup windows and decreases as uploads to the archival location finish. Lag becomes a problem when it keeps increasing and snapshots are not archived within the time required by the SLA Domain.

RSC evaluates archival lag every 6 hours.

When archival lag builds up, RSC alerts you so that you can respond before the cluster fills up. RSC reports two levels of severity:
  • Trending Towards High Lag: Lag is rising and might become a problem.
  • Critically High Lag: Lag is high enough to risk pausing operations and requires immediate action.

RSC delivers archival lag alerts through email notifications (subject: Action Required: High Archival Lag), the RSC notification bell, and warning banners on the Rubrik Cloud Vault dashboard, the Archival Locations page, and the per-location detail page. If a critical lag condition persists, RSC sends at most one alert per day.

Common causes include:

  • Changes to the assigned SLA Domain, including newly added workloads, are generating more snapshots than the system can handle.
  • The target archival location is temporarily unavailable or completely out of storage capacity.
  • Dropped bandwidth or restricted network pipes are slowing down data transmission speeds.
  • The local cluster is running low on CPU or disk space, capping how fast it can process and push out uploads.

If archival lag is not resolved, the cluster can run out of space, which pauses all cluster operations, including new backups, recovery, and archival uploads.

The Resolving Archival Lag dialog box provides recommendations based on the cause of the lag:

The following table describes the archival lag recommendations and their actions.
Recommendation Why Rubrik recommends it Action
Fix cluster access to archival location The cluster cannot reach the archival location, so unsent snapshots fill cluster storage and eventually pause backups. View Location
Increase archival bandwidth Upload bandwidth cannot keep up with the snapshot volume, so snapshots accumulate on the cluster. Edit Throttle
Reduce backup frequency Backup inflow is higher than archival outflow. Snapshots cannot expire locally until they are uploaded to the archival location, so they accumulate on the cluster and it fills up. Edit SLA Domain
Increase disk space on the cluster The cluster is low on disk space. Add physical disk or expire snapshots that are no longer needed. View Cluster

Procedure

  1. Open the Resolving Archival Lag dialog box using one of the following methods:
    • In the archival lag alert email, click View Recommendations.
    • In the RSC notification bell icon, click View Recommendations for the archival lag notification.
    • On the Rubrik Cloud Vault dashboard or the Archival Locations page, click View Recommendations on the warning banner.
    • On the per-location detail page, click View Recommendations on the warning banner.
  2. Review the recommendations grouped under Critically High Lag and Trending Towards High Lag.
  3. To filter the recommendations, select one of the following: select a filter: All, By Locations, By Cluster, or By SLA Domain.
    The By Locations view displays a table with the following columns for each affected archival location:
    • Archival Location: The name of the archival location
    • Lag Severity: The severity status — Critical or Moderate
    • Pending Snapshots: The number of snapshots waiting to upload
    • Cluster: The associated Rubrik cluster
    • SLA Domains: The SLA Domains uploading to this location
    • Recommendations: The recommended actions for the location. Click View to see them.
  4. For each recommendation, select its action to make the change, and then select Done.

Results

RSC applies your changes. As pending snapshots upload to the archival location, archival lag decreases.
