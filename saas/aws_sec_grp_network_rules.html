Network rules for AWS security groups

Information about the networking rules that RSC configures for Polaris-Exocompute-eks-worker-node and Polaris-Exocompute-eks-control-plane security groups.

RSC creates Polaris-Exocompute-eks-worker-node and Polaris-Exocompute-eks-control-plane security groups in each region configured with an Exocompute instance.

The security groups are configured to permit specific types of traffic.

The following table includes the ingress rules for the worker node security group.
Port Source Protocol Description
10250 Control Plane Security Group TCP Needed for Kubernetes (k8s) APIs, such as running kubectl commands and fetching logs.
All Self All Inter-pod communication
The following table includes the egress rules for the worker node security group.
Port Destination Protocol Description
443 0.0.0.0/0 TCP General secure communication required for AWS APIs, ECR access, and other services.
53 0.0.0.0/0 TCP DNS resolution
53 0.0.0.0/0 UDP DNS resolution
123 0.0.0.0/0 UDP Time synchronization
5432 0.0.0.0/0 TCP RDS PostgreSQL access for RDS operations
12800* 0.0.0.0/0 TCP Required for RBA access for application-consistent snapshot
12801* 0.0.0.0/0 TCP Required for RBA access for application-consistent snapshot
Note:
The rules with (*) are added only when you take the first application-consistent snapshot. They are not added by default.
The following table includes the ingress rules for the control plane security group.
Port Source Protocol Description
443 Worker node security group TCP Node to cluster communication
443 Self TCP Lambda communication with EKS control plane needed for private Exocompute setup. For more information about private Exocompute setup, see Set up Exocompute on AWS.
The following table includes the egress rules for the control plane security group.
Port Destination Protocol Description
10250 Worker node security group TCP Needed for Kubernetes (k8s) APIs, such as running kubectl commands and fetching logs.
443 Self TCP Lambda communication with EKS control plane needed for private Exocompute setup. For more information about private Exocompute setup, see Set up Exocompute on AWS.
