Recovering Teams private channels to another channel

Use indexed Microsoft 365 snapshots to recover all content from a Microsoft Teams private channel to another private channel.

Before you begin

  • Ensure that your account has global administrator authorization to recover Teams channels.
  • For private channel recovery, confirm that the Teams app is authenticated. If the Teams app is not authenticated, re-authenticate the Teams app for the tenant.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
  3. On the navigation bar, click Inventory.
  4. Click the Microsoft 365 inventory card.
  5. From the Selected Subscription dropdown menu, select the subscription.
  6. Click Enter Subscription.
  7. Click Teams and select a team.
  8. On the details page for the team, select a snapshot from the calendar view and click Recover.
    Alternatively, you can search for an object to recover.
  9. Click Recover selected content for one channel type and then click Next.
  10. Select Full Channel > Private Channels and click Next.
  11. Select the private channel to recover and then click Next.
  12. Click Recover to a new channel.
  13. Optional: Select Recover with the latest backed up channel permissions to recover the channel along with the most current permissions that were backed up.
  14. Select a target team and then select a channel name.
  15. Click Next.
  16. Enter a name for the new private channel.
  17. Select the team in which to create the channel.
  18. Select a file recovery option.
    OptionDescription
    Recover to the same path Recovers files to the new location using the same path as the original location. Recovering to the same path recovers only objects in folders/files/attachments.

    Recovery of conversations to the same path is not supported.
    Recover to a new folder Recovers objects to a new folder.
  19. For recovery to the same path, select a recovery option.
    OptionDescription
    Append duplicate objects Creates duplicates of the objects and retains the original objects. RSCcreates the duplicates at the file level, not at the folder level.
    Overwrite duplicate objects With duplicate objects, RSC overwrites the old objects with the objects to be recovered. RSC overwrites files at the object level, not at the folder level.
  20. Click Next.
  21. Log in to the Microsoft 365 account to provide RSC with the permissions required for recovering objects to the selected channel and then click Next.
  22. Review the information and click Recover.

Results

RSC starts a task to recover the specified conversations from the selected channel to the specified team channel. When recovered, the messages appear with the original author name and original message time attached to the beginning of each message.

For recovering to the same path, for conversations with attached files, RSC recovers the attached files to the same path under a folder named Source_Channel_Name, where Source_Channel_Name is the name of the source channel to which the attached file originally belonged.

If RSC could not back up some items, you can download a list of items that RSC skipped during backup. For more information, see Downloading a list of Microsoft 365 items skipped during backup.

If RSC skipped recovering some data, you can either export a ZIP archive of the skipped items or download a detailed list of the items. For more information, see Exporting Microsoft 365 items skipped during recovery.
