VM Encryption Detection

VM Encryption Detection identifies encryption on the host, allowing you to receive anomaly alerts for encryption activity on virtual machines. You can use this information to quickly assess the blast radius and recover from such attacks.

Anomaly Detection in Data Threat Analytics scans data from snapshots to detect ransomware attacks that target the file system of the workload object. However, when the ESXi host and the associated virtual machine and virtual disk files are targeted, snapshots fail due to the attack on the ESXi host. Under these circumstances, file systems are compromised. VM Encryption Detection identifies anomalous activity on the virtual machine by scanning backup event errors and flags ransomware attacks that target the host.

Enabling Data Threat Analytics and Anomaly Detection is required for enabling VM Encryption Detection. This feature is available only for vSphere virtual machines.

VM Encryption Detection detects multiple types of ransomware attacks, including attacks that can bring down the ESXi host completely and attacks that encrypt the virtual machine disk (VMDK) extension. In both scenarios, RSC flags backup failures in ESXi hosts as anomalies.

You can view anomalies flagged by VM Encryption Detection on the Events page in Data Protection. To receive email alerts for any anomalies detected, you can configure email notifications in the Settings page. You can recover any affected virtual machines from the anomaly details page.
