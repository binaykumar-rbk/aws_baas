            Each vSphere virtual machine recovery operation in RSC requires a set of RBAC permissions to be applied to specific objects. You can grant minimum permissions when creating a custom role for users who perform vSphere virtual machine recoveries.

            Large file recovery uses VMware tools and disk mount to restore large files efficiently, enhancing the speed for faster data recovery operations.

            When you are unable to access a vSphere virtual machine or when a virtual machine is deleted, create a virtual machine from a point-in-time copy of the source virtual machine.

          • Creating live mounts in a batch

            When you are unable to access several vSphere virtual machines, or when multiple virtual machines are deleted and are required to be live-mounted together, create live mounts in a batch.

          • Creating a Live Mount of a virtual disk snapshot of a vSphere virtual machine

            A Live Mount creates a virtual disk or disks from point-in-time copies of the disks on a source vSphere virtual machine. The recovered virtual disks use the Rubrik cluster as the datastore.

Powering off after Instant Recovery or Live Mount

Power off a mounted virtual machine from the Live Mounts page of the RSC web UI.

About this task

The Live Mounts page lists all recovered virtual machines that were mounted using Instant Recovery or Live Mount from the local Rubrik cluster.

Procedure

  1. Log in to RSC.
  2. Open the app tray and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, click Live Mounts.
    The Live Mounts page appears.
  4. Locate the recovered virtual machine to power off.
    To help find a specific virtual machine, use the filters, sort the entries by column heading, or use the search field.
  5. Open the ellipsis menu for the recovered virtual machine and select Power Off.
    A confirmation message appears.
  6. Click Power Off.

Results

RSC initiates a task for the Rubrik cluster to gracefully power down the selected virtual machine.
