        • Set up AWS protection

          Discover your AWS workloads, add your AWS accounts to RSC, and manage the accounts after you add them. The steps depend on the deployment model.

        • Set up AWS workloads protection

          You can set up SLA Domains to apply data protection policies, ensuring automatic and hierarchical protection of AWS accounts and individual AWS workloads, with granular control overriding higher-level assignments.

        • Manage Amazon EC2 instances and EBS volumes

          After you set up protection for Amazon EC2 instances and EBS volumes, RSC takes automated snapshots of those instances and volumes based on the configured policies in SLA Domains. You can also take on-demand snapshots, refresh AWS accounts, and add AWS custom tags for better resource management.

        • Manage Amazon RDS and Aurora databases

          RSC protects the data and resources of Amazon RDS and Amazon Aurora databases.

        • Manage Amazon S3

          With RSC, you can protect and recover your Amazon S3 buckets and objects.

        • Manage Amazon DynamoDB

          RSC secures Amazon DynamoDB tables with automated snapshots governed by SLA Domain policies. You can gain insights from detailed snapshot data and optimize resources using on-demand account refresh and AWS custom tags.

        • Manage AWS Glue Iceberg Tables

          RSC protects Iceberg tables registered in your AWS Glue catalog with automated snapshots configured in SLA Domain policies. You can view inventory details, manage protection assignments, and recover Iceberg tables from the AWS Glue Iceberg Tables inventory page.

        • Manage AWS S3 Tables

          RSC protects Iceberg tables stored in your AWS S3 table buckets with automated snapshots configured in your SLA Domain policies. You can view inventory details, manage protection assignments, and recover Iceberg tables from the AWS S3 Tables inventory page.

        • Recover AWS workloads

          After RSC takes snapshots of your AWS workloads, you can recover the required workloads.

Required permissions for native AWS protection

Information about the permissions that RSC requires to protect AWS workloads.

The following table outlines the permissions that RSC requires for various aspects of AWS protection.
Permission Access level Use case
ec2:AssociateIamInstanceProfile Write To associate an IAM instance profile with an EC2 instance during EC2 export.
ec2:AttachVolume Write
  • To restore EC2 instances and attach exported EBS volumes.
  • To export crash-consistent snapshots of an EC2 instance.
  • To export EBS volumes and replace them wherever attached.
  • To attach the temporary EBS volume to an Amazon Elastic Kubernetes Service (EKS) cluster for indexing and storage tiering.
ec2:CopyImage Write To perform the following tasks:
  • Cross-region export of EC2 instances
  • Cross-region replication of EC2 instance snapshots
ec2:CopySnapshot Write To perform the following tasks:
  • Cross-region export and replication of EBS volumes
  • Cross-region export and replication of crash-consistent snapshots of EC2 instances
ec2:CreateImage Write To create an image of an EC2 instance for backup.
ec2:CreateSecurityGroup Write To create a security group with no connectivity for the AWS export virtual machine in a powered-off state.
ec2:CreateSnapshot Write To create a snapshot of an EBS volume for backup.
ec2:CreateSnapshots Write To create crash-consistent snapshots of an EC2 instance.
ec2:CreateTags Tagging To assign metadata tags to the created resources such as EBS volumes, EC2 instances, images, snapshots, and security groups.
ec2:CreateVolume Write
  • To export EBS volumes.
  • To restore EC2 instances.
  • To export crash-consistent snapshots of an EC2 instance.
  • To create a temporary EBS volume to perform indexing for file search and recovery and storage tiering.
ec2:DeleteSnapshot Write

Requires the resource to have the rk_component tag with the value set to Cloud Native Protection.
  • To delete EBS volume snapshots associated with expired backups.
  • To delete associated snapshots when deleting an Amazon Machine Image (AMI) while reverting the Create EC2 instance snapshot task or exporting the EC2 instance snapshot to a different region.
  • To delete snapshots when reverting the Create EBS volume snapshot task.
  • To delete snapshots when exporting the EBS volume snapshot to a different region.
  • To delete crash-consistent snapshots of excluded EBS volumes.
  • To delete snapshots when deleting an AWS account.
  • To delete snapshots after expiry.
  • To delete temporary snapshots created during replication and export.
ec2:DeleteVolume Write

Requires the resource to have the rk_component tag with the value set to Cloud Native Protection.
  • To delete the EBS volumes launched from the backup if a restore or export EC2 instance task fails in the middle.
  • To delete temporary EBS volumes launched for file indexing and storage tiering.
ec2:DeleteTags Tagging
  • To overwrite existing tags when restoring tags in the EC2 instance restore job.
  • To delete Rubrik metadata tags when the tag limit is exceeded.
  • To delete Garbage Collection (GC) tags when the GC task is no longer required for the resource.
ec2:DeregisterImage Write
  • To delete the Amazon Machine Image (AMI) associated with an expired backup.
  • To delete images while undoing the EC2 instance snapshot task.
  • To delete images after copying them to a new region during the cross-region export.
  • To delete AMIs after a snapshot expiry.
  • To delete any temporary AMI created during replication and export.
ec2:DescribeAvailabilityZones Read To retrieve the list of availability zones while exporting EBS volume and EC2 instance snapshots.
ec2:DescribeHosts Read To retrieve information about dedicated hosts in your AWS environment for EC2 instance recovery tasks.
ec2:DescribeImages Read
  • To track the image creation status in the EC2 backup task.
  • To retrieve image details for the recovery tasks.
  • To periodically ensure that the AMI associated with RSC backups is still available and not deleted by an external actor.
ec2:DescribeInstances Read
  • To retrieve the list of EC2 instances during the refresh task.
  • To retrieve instance details during snapshot and recovery tasks.
ec2:DescribeInstanceTypeOfferings Read To list the instance types available in a specific region or availability zone during the virtual machine export flow.
ec2:DescribeKeyPairs Read
  • To retrieve the list of SSH key pairs during the virtual machine recovery.
  • To track the associated key pairs for EC2 instances when a backup is taken.
ec2:DescribeLockedSnapshots Read To enable RSC to retrieve and verify the AWS EBS snapshot lock details for primary and replicated EC2 instance and EBS volume snapshots.
ec2:DescribeSecurityGroups Read
  • To retrieve the list of security groups during the account refresh task.
  • To retrieve the list of security groups while exporting EC2 instance snapshots.
ec2:DescribeSnapshots Read
  • To track the snapshot creation status during the EBS volume snapshot task.
  • To retrieve snapshot details for the recovery tasks.
  • To periodically ensure that the snapshot associated with RSC backups is still available and not deleted by an external actor, for example, a user-initiated script.
ec2:DescribeSnapshotAttribute Read To perform a check to determine if an EBS volume snapshot is from the AWS marketplace or not.
ec2:DescribeSubnets Read
  • To retrieve the list of subnets during the account refresh task.
  • To retrieve the list of subnets while exporting EC2 instance snapshots.
ec2:DescribeTags Read, Tagging
  • To back up the tags attached to an EC2 instance during backup.
  • To avoid the tag limit while assigning tags to new resources.
ec2:DescribeVolumeAttribute Read To enable RSC to identify EBS volumes launched from the AWS marketplace.

You cannot perform file recovery and storage tiering for marketplace EBS volumes.
ec2:DescribeVolumes Read
  • To retrieve the list of EBS Volumes during the refresh task.
  • To retrieve volume details in various snapshot and recovery tasks.
ec2:DescribeVolumesModifications Read To monitor the status of volume modifications for specified EBS volumes.
ec2:DescribeVpcs Read
  • To retrieve the list of all Virtual Private Clouds (VPC) while exporting EC2 instance snapshots.
  • To retrieve the list of VPCs during the account refresh task.
ec2:DetachVolume Write
  • To detach the existing volumes to replace them with recovered copies during restoring an EC2 instance.
  • To detach an existing EBS volume when the Replace where attached option is selected at the time of exporting an EBS volume.
  • To detach the EBS volume from the temporary EKS cluster when the file search is enabled for an EC2 instance or EBS volume.
ec2:GetEbsEncryptionByDefault Read To check if default EBS encryption is enabled in the AWS account of a user for the given region.
ec2:LockSnapshot Write

Requires the resource to have the rk_component tag with the value set to Cloud Native Protection.

 To enable RSC to apply a native EBS snapshot lock on EC2 instance and EBS volume snapshots in governance mode for:
  • Primary snapshots: Immediately after snapshots are created in the source AWS account.
  • Replicated snapshots: Immediately after a replication snapshot has been created in the target AWS account.
ec2:ModifyImageAttribute Write To modify the description of EC2 instance snapshots created by RSC.

The image description is used for identifying all GC leaked images.
ec2:ModifyInstanceAttribute Write

Requires the resource to have the rk_component tag with the value set to "Cloud Native Protection" or "Cloud Cluster".

 To change security groups of an EC2 instance from the no connectivity security group to a user-specified security group while exporting EC2 instance in a powered-off state.
ec2:ModifySnapshotAttribute Write To share EBS snapshots with other AWS accounts for cross-account replication.
ec2:ModifyVolume Write

Requires the resource to have the rk_component tag with the value set to Cloud Native Protection or Cloud Cluster.

 To perform EBS volumes resizing during performance updates, specifically for Rubrik Cloud Cluster Elastic Storage (ES). This enables updating volume type, size, or performance without detaching the EBS volume.
ec2:RegisterImage Write To create an AMI during the export flow.
ec2:ReplaceIamInstanceProfileAssociation Write To replace an IAM instance profile for the EC2 instance during EC2 export.
ec2:UnlockSnapshot Write

Requires the resource to have the rk_component tag with the value set to Cloud Native Protection.

 To enable RSC to remove a native EBS lock from primary or replicated EC2 instance and EBS volume snapshots.
This is required for:
  • Automated deletion: Unlocking expired snapshots during the Garbage Collection (GC) process.
  • Manual deletion: Unlocking snapshots before their expiration date following Quorum Authorization (QAuth) approval.
ec2:RevokeSecurityGroupEgress Write

Requires the resource to have the rk_component tag with the value set to "Cloud Native Protection".

 To remove the default egress rule from no connectivity security group for exporting EC2 instances in a powered-off state.
ec2:RunInstances Write To launch a virtual machine from a backup.
ec2:StartInstances Write To start a virtual machine that was restored with new disks.
ec2:StopInstances Write To stop an EC2 instance.

When restoring a virtual machine, disks can only be replaced when the EC2 instance is stopped.
ec2:TerminateInstances Write

Requires the resource to have the rk_component tag with the value set to "Cloud Native Protection" or "Cloud Cluster".

 To terminate EC2 instances created during a failed export or restore operation.
kms:CreateGrant Permissions management To enable EC2 service to use the Customer Managed Key (CMK) on behalf of the user.

Example: When an EBS volume snapshot is shared from a customer account (C1) to a Rubrik account (C2), the EC2 service requires permission to create KMS key grants for account C2. This enables EC2 to decrypt the snapshot and make the data accessible on the Rubrik side.

This permission enables RSC to use a customer-managed KMS key to access workload data, such as AWS EC2, EBS, RDS, and S3 data, during backup and recovery operations in Rubrik Cloud Vault.
kms:Decrypt Write To perform the custom CMK flow while exporting EC2 instance or EBS volume.
kms:DescribeKey Read To perform the custom CMK flow while exporting EC2 instance or EBS volume.
kms:Encrypt Write To perform the custom CMK flow while exporting EC2 instance or EBS volume.
kms:GenerateDataKey Write To perform the custom CMK flow while exporting EC2 instance or EBS volume.
kms:GenerateDataKeyWithoutPlaintext Write To perform the custom CMK flow while exporting EC2 instance or EBS volume.
kms:ListKeys Read To display Key Management Service (KMS) keys for the AWS account in a region.
kms:ListAliases Read To display KMS aliases for the AWS account in a region.
kms:ReEncryptFrom Write To perform the custom CMK flow while exporting EC2 instance or EBS volume.
kms:ReEncryptTo Write To perform the custom CMK flow while exporting EC2 instance or EBS volume.
s3:AbortMultipartUpload Write To perform the multipart upload.

It is used in the file recovery job.
s3:CreateBucket Write To create a bucket.

It is used in the file recovery job.
s3:DeleteObject Write To remove an object from an S3 bucket.
s3:GetBucketObjectLockConfiguration Read To retrieve the Object Lock configuration for a bucket to determine Write Once Read Many (WORM) status.
s3:GetBucketVersioning Read To retrieve the versioning state of an S3 bucket, such as Enabled, Suspended, or Unversioned.
s3:GetLifecycleConfiguration Read To retrieve the lifecycle rules set on a bucket, such as transition or expiration policies.
s3:GetObject Read To retrieve objects from an S3 bucket during backup or indexing tasks.
s3:GetObjectRetention Read To retrieve the retention settings, such as mode and Retain-until date for a specific S3 object.
s3:GetObjectVersion Read To retrieve a specific version of an object from a version-enabled S3 bucket.
s3:ListAllMyBuckets Read To list buckets.

It is used when listing S3 bucket endpoints.
s3:ListBucket Read To list bucket objects and check if the bucket exists.

It is used in the download job.
s3:ListBucketVersions Read To list metadata about all versions of the objects within an S3 bucket for point-in-time inventory.
s3:PutBucketObjectLockConfiguration Write To configure the Object Lock configuration for a bucket to determine WORM status.
s3:PutObject Write To upload objects.

It is used in the file recovery job.
s3:PutBucketTagging Write To add tags to S3 buckets.

It is used in the file recovery job.
s3:PutBucketVersioning Write To modify the versioning state of an S3 bucket, such as Enabled or Suspended.
s3:PutObjectRetention Write To apply the retention settings, such as mode and Retain-until date for a specific S3 object.
s3:PutObjectTagging Write To add tags to S3 objects.
s3:PutLifecycleConfiguration Write To configure the lifecycle rules set on a bucket, such as transition or expiration policies.
