Disabling RCV locations

You can stop a Rubrik Cloud Vault location from archiving and any other background operations that can change data on the archival location.

About this task

Note:
You cannot disable Rubrik Cloud Vault (RCV) locations created for cloud-native workloads.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, click Infrastructure > Rubrik Cloud Vault.
    The Rubrik Cloud Vault dashboard appears.
  4. Click RCV Locations.
    A list of RCV locations appears.
  5. Click and select Disable Rubrik Cloud Vault.
    The Disable Rubrik Cloud Vault page appears.
  6. Click Disable.
    If you have created a quorum authorization policy for this operation, you need to submit a request for quorum authorization.
  7. For quorum authorization, select a run type action.
    OptionDescription
    Automatically schedule Schedules the action to automatically run after approval.
    Manually schedule Schedules the action to run within 24 hours after the approval. Actions not run 24 hours after approval will expire.
  8. Optional: For quorum authorization, in Comment, enter a comment to provide additional details about the request.
  9. For quorum authorization, click Submit Request.

Results

RSC stops archiving and any other background operations on the RCV location. If you have created a quorum authorization policy, RSC completes the action according to the specified run type option after the request is approved.
Related concepts
  • Quorum authorization for Rubrik Cloud Vault management actions
    You can protect the management actions on your Rubrik Cloud Vault locations using quorum authorization. When enabled, quorum authorization requires the requesters of the protected actions to obtain additional approvals to perform the requested actions.
