Testing a failover

Test a failover for a selected Recovery Plan using a point in time that you choose.

Before you begin

You must assign Change Memory and Create Folder privileges in the vCenter Server so that failover operations succeed.

About this task

This topic describes a high impact change. You can deploy this change to RSC on your own schedule before Rubrik deploys it automatically. For more information, see Managing high impact changes.

Procedure

  1. Log in to RSC.
  2. Click and select Orchestrated Recovery.
    The Objects page appears.
  3. Click Recovery Plans.
    The Recovery Plans page appears, listing all Recovery Plans.
  4. Click a Recovery Plan from the list.
    The Recovery Plan details page appears.
  5. Click and select Start Test Failover.
    The Start Test Failover wizard appears and displays the Recovery Details page.
  6. In Recovery Name, enter a name for the test recovery.
  7. Under Error Handling, select a response for errors that occur during the test failover.
    OptionDescription
    Pause and manually resume after assessing errors Pauses the test failover when errors occur. You can manually resume the test failover after the errors are cleared. This is the default option.
    Abort and clean up recovered objects Aborts the test failover when errors occur and cleans up the recovered objects.
  8. Optional: Under Reconfiguration, select Ignore network and post-recovery script errors.
    When you select this check box, the recovery continues even if a network reconfiguration or post-recovery script error occurs. Post-recovery scripts do not run when a network reconfiguration error occurs.
  9. Click Next.
    The Select Snapshots page appears.
  10. In Point in Time, select a date and time.
    RSC automatically selects the closest snapshot taken prior to that time for each virtual machine.
  11. Optional: Select Only use non-quarantined and non-anomalous snapshots.
    When you select this check box, RSC uses only snapshots that are not quarantined and are not anomalous, based on the Anomaly Detection outcome.
  12. Optional: To use a different snapshot for a virtual machine, click for the virtual machine, select a snapshot, and click Save.
  13. Click Recover.

Results

RSC starts the test failover and displays a Recovery Plan event on the Events tab of the Recovery Plan details page and on the RSC Events page.
