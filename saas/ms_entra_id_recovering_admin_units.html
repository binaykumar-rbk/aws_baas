Recovering Microsoft Entra ID administrative units

Recover Microsoft Entra ID administrative units, including their user, group, and device membership, from a snapshot taken at a specific point in time.

Before you begin

Recovering Microsoft Entra ID administrative units requires a snapshot of an administrative unit. Taking that snapshot requires specific permissions on the Microsoft Entra ID directory. For more information, see Permissions for Microsoft Entra ID.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, select Inventory > Identity > Microsoft Entra ID Inventory > All > Microsoft Entra ID.
    The inventory list for Microsoft Entra ID appears.
  4. In the Domain column, click a Microsoft Entra ID directory.
    Alternatively, you can enter a name in the search field or use the filters at the top of the list.
    The local page for the directory appears, where the Snapshots card displays the month view.
  5. On the Snapshots calendar, select a day marked with a green dot.
    The green dot indicates that RSC successfully took a snapshot on that day.
    The Snapshots card displays the Day view with a list of snapshots.
  6. Hover over a snapshot and then click Recover.
    RSC does not recover objects that are not present in the selected snapshot.
    The Microsoft Entra ID Recovery wizard appears.
  7. Select Granular Recovery and click Next.
    The Recovery Destination page appears.
  8. Select Recover to original directory and click Next.
    RSC supports In-Place Recovery only to the original directory.
    The Select Objects page appears.
  9. In the object tree, expand Entra ID and click Administrative Units.
    The list of administrative units available for recovery at the time of the snapshot appears.
  10. Select one or more administrative units to recover from the list.
    Recovering the administrative unit does not recover the user objects or group objects contained within the administrative unit. To recover these objects, select them in the object tree.

    For device recovery, RSC recovers the administrative unit device membership information as part of the snapshot.

  11. Optional: Click an administrative unit name to view the details about the contents.
    You can view information about the users, groups, and devices contained within the selected administrative unit.
  12. Click Next.
    The Conflict Resolution page appears.
  13. Select how to recover attributes and relationships for existing objects in the target directory.
    OptionDescription
    Overwrite everything Reverts all attributes and relationships to their snapshot state. RSC deletes changes made in the target directory after RSC took the snapshot.
    Overwrite and preserve Reverts single-valued attributes to their snapshot state. Merges multi-valued attributes and relationships with existing values. Restores structurally complex attributes in full from the backup and preserves existing relationships over the snapshot to maintain configuration integrity.
    Skip existing objects Recovers missing objects only. Establishes relationships only among the newly recovered objects. Existing objects in the target directory are unchanged.
    When you recover an object that already exists in the Microsoft Entra ID directory or in the recycle bin, unrecoverable relationship properties remain unchanged, and RSC updates the other properties for the object. When you recover a permanently deleted object, unrecoverable relationships appear as blank.
  14. Click Next.
    The Confirmation page appears.
  15. Acknowledge the text regarding recovery of users and groups synchronized from an on-premises Active Directory (AD).
    Microsoft Entra ID recreates users and groups synchronized from AD with new identifiers, and links users by user principal name and groups by group name. Objects that still exist or are in the Recycle Bin at the time of recovery keep their original identifiers.
  16. Optional: If RSC requires additional permissions to recover the selected objects, assign the permissions.
    Important:
    Because Microsoft 365 depends on Microsoft Entra ID for metadata recovery, set the directory to Full access before performing a full Teams or SharePoint relic recovery to a directory that uses OAuth and JIT access. This prevents potential data loss.

    For more information, see Microsoft Entra ID just-in-time access.

  17. Click Recover.

Results

RSC recovers the Microsoft Entra ID administrative unit object and relationships to a specific point in time.
