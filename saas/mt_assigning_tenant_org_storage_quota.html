    • Multitenancy with RSC

      Rubrik Security Cloud multitenancy uses a multi-account management framework that enables a single primary Rubrik Security Cloud account to provision, manage, and monitor multiple Rubrik Security Cloud environments. The architecture is designed to support both shared infrastructure and strict physical isolation.

    • Tenant comparison

      Rubrik Security Cloud offers various multitenancy models to support different requirements for resource isolation, administrative autonomy, and access to advanced security applications.

    • Dedicated tenants

      Dedicated Rubrik Security Cloud tenants provide Managed Service Providers with physically isolated Rubrik Security Cloud instances for their clients, ensuring complete data separation and feature parity across security applications.

    • Shared clusters

      Shared clusters provide software-enforced isolation between dedicated tenants provisioned on a single RSC cluster, ensuring data separation and feature parity while maximizing hardware ROI.

    • Network Connectors

      Network Connectors enable Rubrik to back up and recover workloads in environments where network segmentation, NAT, or overlapping IP address ranges prevent the Rubrik cluster from directly reaching tenant workloads.

Assigning the tenant organization storage quota

Assign storage-based quota to a tenant organization to restrict resource utilization and protect resource availability.

Before you begin

You require a user account with the administrator role to complete this task.

Procedure

  1. Log in to RSC.
  2. Click and select Settings.
    The Settings menu appears.
  3. Click Organizations > Management.
    The Organizations page appears.
  4. Click in the row for the organization and click Manage Quotas.
    You can also access the Manage Quotas dialog box from the organization details page.
    The Manage Quotas dialog box appears.
  5. Click Set Quota for the Rubrik cluster that you want to assign a storage quota.
    The dialog box lists all the clusters that the organization has access to.
    The dialog box shows the Set Quota for the cluster page.
  6. Turn on Storage Quota.
    The dialog box displays the fields for the soft limit and the hard limit.
  7. In the Soft Limit and Hard Limit fields, enter the values for the storage quota limits.
    The soft limit value must be less than or equal to the hard limit. You can switch between GB and TB for the limit values.
  8. Click Done.
    You can assign storage quotas for multiple organizations.
  9. Click Save.
    RSC displays a message that the organization quotas have been updated.

Results

RSC assigns the specified storage quotas to the organizations.
