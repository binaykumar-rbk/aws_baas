Adding Azure Files systems

Add an Azure Files system as a data source using RSC. After adding the system, you can discover and protect its shares and exports in RSC.

Before you begin

Ensure the following:
  • The RSC user account must have the necessary permissions to add a new data source.
  • You have obtained the IP address or the hostname of the Azure Files storage account that you want to add.

    You can get the IP address or the hostname of the Azure Files storage account from the Azure portal. The Azure Files documentation provides more information about viewing the IP address or the hostname of the Azure Files storage account.

  • You have obtained the storage account name and an access key for the account from the Azure portal.

    The Azure Files documentation provides more information about storage account name and access key of the Azure Files storage account.

  • For NFSv4 file shares, ensure that you have configured the NAS CD virtual machine and NFSv4 file share in Azure Files to run on the same Virtual Network (VNet). The Azure Files documentation provides more information about configuring Virtual Network.

About this task

RSC supports the following:
  • Standard and premium tiers in Azure
  • Windows New Technology LAN Manager (NTLM) for authenticating users accessing Azure Files
  • Server Message Block (SMB) protocol versions 3.1.1, 3.0, and 2.1
  • Network File System version 4 (NFSv4) protocol

Procedure

  1. Log in to RSC.
  2. Click and select Settings.
    The Settings menu appears.
  3. Click Data Sources and select NAS Cloud Direct Systems.
    The NAS Cloud Direct Systems page appears.
  4. Click Add System.
    The Add a System dialog box appears.
  5. From the NAS Cloud Direct Site dropdown list, select the Rubrik cluster for adding the system.
  6. From the System Type dropdown list, select Azure Files.
  7. In IP/Hostname, enter the FQDN (recommended) or IP address of the Azure Files management interface.
    The IP address is the management endpoint IP address for the file system that you want to add from your Azure Files console.

    Enter the URL of the hostname in the following format: <name of the Azure Files storage account>.file.core.windows.net.

  8. In the Account Access section, enter the user credentials of an account in Azure Files with backup and recovery permissions.
    For Username and Password, provide the storage account name and the access key respectively for the account from the Azure portal.
  9. Click ADD.

Results

RSC initiates the task to add the Azure Files system and displays a message indicating that the process has started. RSC imports the system asynchronously in the background. You can monitor the progress and verify the successful addition of the system on the Event Logs page.
