Downloading the OneLogin metadata file

Create a custom application connector for RSC in OneLogin, then download the OneLogin metadata file.

About this task

Use the OneLogin SAML Test Connector (Advanced) as a template to create a custom application connector for RSC. The SAML Test Connector (Advanced) is configured for SP-initiated single sign-on, and can test if RSC can successfully send and receive SAML assertions.

Procedure

  1. Log in to the OneLogin web UI with a user account that has OneLogin administrator privileges.
  2. On the top bar of the UI, click Administration.
  3. On the top bar of the Administration page, open the Applications menu and select Applications.
    The Applications page appears and displays all configured applications.
  4. Click Add App.
    The Find Applications page appears.
  5. In the search box, enter SAML.
    A list of SAML applications appears.
  6. From the list of SAML applications, select SAML Test Connector (Advanced).
    The Add SAML Test Connector (Advanced) page appears.
  7. In Display Name, enter a name for the RSC connector and click Save.
    The connector name appears on the Applications page unless the Visible in portal switch is toggled off.
    A message indicates that the application was successfully added, and the Applications/SAML Test Connector (Advanced) page appears.
  8. In the upper-right corner of the page, click More Actions and select SAML Metadata.

Results

The web browser downloads the OneLogin metadata file to the default download location.

What to do next

Go to RSC to configure single sign-on, as described in Editing an existing RSC SSO configuration.
