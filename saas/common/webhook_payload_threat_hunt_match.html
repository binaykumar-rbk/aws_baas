Threat hunt file match events

RSC sends one ThreatHuntMatchDetails webhook event per file match detected during a threat hunt.

RSC sends one ThreatHuntMatchDetails event per file match, per scanned object found during a threat hunt. If a snapshot produces more than 500 matches, RSC drops per-match events but always sends the summary event.

Fields in the eventInfo object

The following table describes the top-level fields in the eventInfo object for ThreatHuntMatchDetails events.
Field Description Type Example
HuntID The unique identifier of the threat hunt. String 00000000-0000-0000-0000-000000000000
HuntName The name of the threat hunt. String Hunt-Q1-2026
TotalMatches The total number of file matches found in this event's scanned object. Integer 3
TotalFiles The total number of unique files matched in this event's scanned object. Integer 3
LastDetectionTime The timestamp of the most recent match detected in this event. Timestamp 2026-02-06T10:58:00Z
ThreatMatches An array of per-match objects describing each file match. View Fields in the ThreatMatches array below. Array of objects View the JSON example below.

Fields in the ThreatMatches array

The following table describes each field in a ThreatMatches object.
Field Description Type Example
FilePath The full path of the matched file. String /home/user/suspicious.exe
FileSizeInBytes The size of the matched file in bytes. Integer 102400
HashValues The hashes of the matched file. Each item in the array has a Key and a Value, the hash algorithm and hash string, respectively. Supported algorithms are MD5, SHA1, and SHA256. Array of objects [{"Key": "SHA256", "Value": "addebefe..."}]
MatchType The detection method that produced the match. String Hash, Yet Another Recursive Acronym
ThreatFamily The malware family associated with the match. String Trojan.Generic
ObjectIps The IP addresses of the protected object where the match was detected. Array of strings ["10.0.42.110"]
FileCreationTime The creation timestamp of the matched file, in ISO 8601 format. Timestamp 2026-02-01T14:00:00Z
FileModificationTime The last-modified timestamp of the matched file, in ISO 8601 format. Timestamp 2026-02-05T09:30:00Z
DetectionTime The timestamp when RSC detected the match. Timestamp 2026-02-06T10:58:00Z
FirstDetectedSnapshotDate The timestamp of the earliest snapshot in which this match was detected. Timestamp 2026-02-06T08:00:00Z
LastDetectedSnapshotDate The timestamp of the most recent snapshot in which this match was detected. Timestamp 2026-02-06T10:58:00Z
