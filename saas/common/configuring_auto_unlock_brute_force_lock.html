Configuring auto unlock for brute force lock

As an administrator, you can configure the automatic unlocking of user accounts that have been locked due to brute force attempts.

You can set a locked user account to unlock automatically when the user attempts to log in with the correct login credentials after a specified duration. This auto unlock method is applicable only when a user account was locked by brute force.

By default, the auto unlock duration is set to 30 minutes. An administrator or RSC account owner can change the value of the auto unlock duration. The minimum value is 5 minutes and the maximum value is 4320 minutes, or 72 hours.

Note:
If the auto unlock feature is not enabled by your administrator, your account will not be unlocked automatically. In this case, contact the RSC administrator to unlock the account.

The global and tenant organizations support auto unlocking. When a user account belongs to multiple organizations, the strictest policy among the organizations is applied to unlock the user accounts. That is, the highest value configured for auto unlock among the organizations is applied to unlock user accounts. If auto unlocking is not enabled in any of the organizations to which a user account belongs, then auto unlocking is not applicable to any of the organizations. If auto unlocking is not enabled in the global organization and a stricter policy is enforced, auto unlocking cannot be enabled in the tenant organization.
