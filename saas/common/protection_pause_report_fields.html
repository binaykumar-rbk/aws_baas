Paused Protection report fields

Information about the Paused Protection report fields.

This topic describes a feature or features that Rubrik is gradually rolling out to customers.

The fields in the Paused Protection report depend on the type of report you select: Paused Via Objects, Paused Via Clusters, or Paused Via SLA Domain.
Note:
The Paused By and Paused Since fields are displayed only for cluster pauses and SLA Domain pauses that are initiated on a cluster running Rubrik CDM version 9.5.1 or later. For pauses initiated on earlier cluster versions, these fields are not displayed in the report.

Paused Via Objects report

The following table lists the fields in the Paused Via Objects report.
Field Description
Object The name of the object with directly paused protection.
Object Type The type of the paused object, such as a virtual machine or a database.
SLA Domain The SLA Domain assigned to the object.
Cluster The Rubrik cluster that protects the object. For cloud-native objects, this field shows Rubrik Security Cloud.
Paused By The user who paused protection for the object.
Pause Notes The note added when the user paused protection. If no note was added, this field shows two dashes (--).
Paused Since The date when the user paused protection and the duration of the pause.

Paused Via Clusters report

The following table lists the fields in the Paused Via Clusters report.
Field Description
Cluster The name of the Rubrik cluster with paused protection.
Paused By The user who paused protection for the cluster.
Paused Since The date when the user paused protection and the duration of the pause.

Paused Via SLA Domain report

The following table lists the fields in the Paused Via SLA Domain report.
Field Description
SLA Domain The name of the SLA Domain through which the user paused protection.
Cluster The cluster that is paused through the SLA Domain.
Paused By The user who paused protection for the cluster.
Paused Since The date when the user paused protection and the duration of the pause.
