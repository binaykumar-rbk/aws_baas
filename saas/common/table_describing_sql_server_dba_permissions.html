      • Local users

        You can manage local user accounts on RSC.

      • SSO users and groups

        You can manage SSO users and groups together from a single page in RSC. SSO groups map identity provider groups to roles, and you can assign roles directly to individual users as needed.

      • Service accounts

        RSC uses service accounts to represent services and client applications that need to invoke RSC APIs.

      • Personal access tokens

        Personal access tokens enable RSC users to authenticate to the RSC API under their own identity, outside of the RSC web UI.

      • Troubleshooting permissions

        Information about how you can troubleshoot permission issues when a user or service account cannot perform an intended task.

      • Import users and roles to RSC

        You can import users and roles created on the Rubrik cluster to manage them on RSC. After import, you can view the CDM RBAC migration summary report for confirmation or for further changes to users and roles.

      • Federated access

        Federated access enables RSC user and service accounts to access connected Rubrik clusters, including Rubrik NAS Cloud Direct clusters. This access is provided through the RSC user interface using Single Sign-On, eliminating the need for separate login credentials.

      • Privileged access management

        You can create and manage API credentials to use with the Privileged Access Management solution.

    • Quorum authorization

      Quorum authorization is a security feature that requires additional approvals before a requester can perform data-modifying actions in RSC.

Table describing SQL Server database administrator permissions

Information about role-based access control permissions required for database administrators to perform actions on SQL Server.

A Yes in the Required for DBA column indicates that this permission is required for a database administrator (DBA) to back up, restore, export, and live mount databases in their environment.
Permissions group Permission Description Required for DBA
View View protectable objects Allows the DBA to view objects in RSC such as hosts and databases. Yes
View Refresh data sources Allows the DBA to refresh the host or instance to account for changes such as adding or deleting databases. Yes
Protection Manage protection Allows the DBA to assign SLA Domains to objects such as instances and databases. No
Protection Take On-Demand Snapshots Allows the DBA to take database snapshots. Yes
Protection Delete snapshot Allows the DBA to delete snapshots and logs. No
Recovery Download from data center archival location Allows the DBA to download snapshots and logs from the archive location to the Rubrik cluster. No
Recovery Mount snapshot Allows the DBA to perform a Live Mount. Yes
Recovery Export files Allows the DBA to export files to non-original hosts. Required to manage log shipping. No

Yes if the DBA needs to manage log shipping.
Recovery Export snapshots Allows the DBA to export databases to an alternative location. Yes
Recovery Download files Allows the DBA to download snapshots and log backup files. NA
Recovery (Oracle only) Restore over original Allows the DBA to perform an in-place recovery of a database. Yes
Recovery Download from replication target Allows the DBA to download snapshots and logs from the replication location to the Rubrik cluster. NA
Data Source Management NA For selected object types, allows the DBA to add, edit, and delete resources that contain protectable objects and recovery targets. No
