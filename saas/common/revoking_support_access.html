Revoking support access

A user with the Grant Own Support Access or Grant All Support Access permission can revoke an existing support access grant.

Before you begin

You must have the Grant Own Support Access or Grant All Support Access permission, or the owner or administrator role. With only the Grant Own Support Access permission, you can revoke the support access instances that you grant.

Procedure

  1. Log in to RSC.
  2. Click and select Settings.
    A new tab displaying the settings menu opens in your browser.
  3. Click Customer Support and select Support Access.
    The Support Access page appears.
  4. Click for a support access instance and select Revoke Access.
    You can only revoke access for a support access instance that is in the open state.
    A confirmation message appears.
  5. Click Revoke.

Results

RSC revokes the selected support access instance and automatically logs out all associated support sessions.
