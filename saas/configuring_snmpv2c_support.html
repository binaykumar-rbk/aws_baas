Configuring SNMPv2c and SNMP v3 support

To allow an SNMP manager to poll the Rubrik cluster, configure SNMPv2c and SNMP v3 on the Rubrik cluster.

Procedure

  1. Log in to RSC.
  2. Open the app tray and select Settings.
    A tab displaying the Settings menu opens on your browser.
  3. Click Notifications and select SNMP.
    The SNMP page appears and displays the list of clusters.
  4. Select a cluster from the list.
    You can select multiple clusters simultaneously to configure SNMP.
  5. Click Configure SNMP.
    The Configure SNMP dialog box appears.
  6. To enable SNMP, click the SNMP toggle button.
  7. Enter the community string for SNMP v2c Settings.
  8. Enter the username, authentication password, and privacy password for SNMP v3 Settings.
    You can also add another SNMP user for SNMP V3 settings.
  9. Click Configure.

Results

The Rubrik cluster is configured for SNMP v2c and SNMP v3 support.
