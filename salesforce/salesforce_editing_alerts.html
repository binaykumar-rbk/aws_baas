Editing smart alerts for Salesforce

Edit the criteria and settings of an existing alert to adjust monitoring thresholds or notification preferences.

About this task

This feature is available through Rubrik AI or through the Rubrik Security Cloud UI. To use the AI option, Rubrik AI must be enabled for your account.

Procedure

  1. Log in to RSC.
  2. Click and select SaaS App Protection.
    The SaaS Apps dashboard appears.
  3. Click the Salesforce inventory card.
    The details page for the Salesforce instance appears.
  4. Click and select Manage Smart Alerts.
  5. For the alert you want to edit, click , and then choose a method for editing it.
    • To use Classic UI, select Edit Alert. The Classic UI edit wizard opens with the alert's current values.
    • To use Rubrik AI, hover over Edit Alert and click the icon. The Rubrik AI canvas opens.
  6. Update the alert criteria as needed, and then click Save.

Results

The alert is updated with the new information.
