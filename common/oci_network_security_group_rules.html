Rubrik Cloud Cluster Elastic Storage on OCI network security group rules

Rubrik Cloud Cluster Elastic Storage on Oracle Cloud Infrastructure requires specific network security group rules, including inbound and outbound access for SSH, HTTPS, and communication between cluster nodes and the Rubrik Backup Service.

Rubrik Cloud Cluster Elastic Storage on OCI requires specific rules for the network security group. The network security group consists of inbound and outbound rules that control access to and from the Rubrik Cloud Cluster Elastic Storage nodes. At a minimum, the network security group must include the following inbound rules:

  • Allow SSH access on port 22 for Rubrik CLI sessions.
  • Allow HTTPS access on port 443 for Rubrik CDM web UI sessions.
  • Allow outbound HTTPS access on port 443 to the IP address that resolves from URL https://customer.my.rubrik.com.

The network security group requires allowing all nodes within the cluster to communicate with each other. This requires the network security group ID, which generates after creating a network security group that includes the other rules.

In addition, the network security group must have an outbound rule that allows all outbound traffic from the cluster. This rule enables the cluster to back up data on client machines, and to communicate with Rubrik services.

Protected hosts require a separate network security group. This security group must include a rule that allows Rubrik Cloud Cluster Elastic Storage to establish a connection with the Rubrik Backup Service on ports 12800 and 12801.

The Oracle OCI documentation describes configuring network security group rules.
