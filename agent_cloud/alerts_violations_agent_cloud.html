Alerts and violations

Alerts and violations are the findings that your policies produce. An alert is a specific action or message that broke a policy. A violation is a standing configuration that breaks one.

For example, Agent Cloud raises a violation when an agent is configured with a delete_file tool that a policy forbids, whether or not the agent ever calls it. It raises an alert when an agent actually calls the tool. Every policy produces findings, whatever its enforcement mode. A Block policy also stops the action on connections that support blocking.

Alerts

Click Runtime > Alerts. Alerts are grouped. Select a group to view its alerts, and select an alert to open its details:

  • Overview: A reasoning summary. The agent, host, tool, identity, and application. What triggered the alert, its severity, the policy broken, and when it was raised. For policies judged by SAGE, an Alert Reasoning section explains the judgment.
  • Timeline: The session timeline around the alert.
  • Raw Reasoning: The full reasoning from SAGE for a blocked action. Available only for alerts from Block policies.

Alerts from blocked actions show a Blocked chip and are recorded as already remediated. You can select an alert to open the Alert details tray, and then select the policy violation to open the Remediate tray.

Triage alerts and violations

Alerts and violations start as Open. To change the status, click Open in the details and select one:

  • In Progress: You are investigating or addressing it.
  • Remediated: You resolved the issue or rewound the action.
  • Dismissed: You reviewed it and no action is needed.

Alerts can also be Closed, a final state that needs no further action.

To act on an alert or violation, click Remediate:

  • Rewind Action: Undo the agent action. For more information, see Rewinding an agent action.
  • Mark as Safe: Add a policy exception so that Agent Cloud allows the activity from now on. Marking as safe always adds an exception. If a single finding was a false positive but the policy should keep evaluating the same activity, set the status to Dismissed instead. For more information, see Marking alerts and violations as safe.
Related concepts
  • Govern and control
    Agent Cloud policies are the governance rules that define the acceptable behavior for your AI agents. Use them to detect risky activity and, on connections that support it, stop it.
  • How policies work
    A policy is a named rule with a severity that Agent Cloud evaluates against your agents, tools, and sessions. When agent activity breaks a policy, Agent Cloud records a violation or an alert and, depending on the policy's enforcement mode, can stop the action.
  • Discover and observe
    Agent Cloud builds an inventory of the agents, tools, identities, models, and MCP servers in your environment, and records what each agent does, session by session.
