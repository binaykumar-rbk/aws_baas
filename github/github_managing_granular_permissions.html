Managing granular permissions for GitHub organization

Update granular permissions for a GitHub organization when needed.

About this task

Use the Manage Permissions wizard to install the Rubrik GitHub Restore app or to enable Developer Collaboration protection for an organization that you already added.

Procedure

  1. Log in to RSC.
  2. Click and select Data Protection.
    The Data Protection dashboard appears.
  3. On the navigation bar, click Inventory.
    The Inventory page appears.
  4. Click GitHub.
    The GitHub inventory page appears.
  5. Click Organizations.
    A list of organizations appears.
  6. Click for an organization and click Manage Permissions.
    The Manage Permissions wizard appears.
  7. Optional: Select the Developer Collaboration permissions for pull requests and issues.
    OptionAction
    Basic Select this option to back up pull requests and issues.
    Recovery Select this option to also grant the permissions required to recover them.
    Note:
    Without the Basic permissions, RSC does not back up pull requests and issues.
  8. Optional: Click Save.
    The app status changes to update available.
  9. Optional: Click Install App for the updated app, and then follow the GitHub prompts to approve the permissions.
  10. Click Install App for the Rubrik GitHub Restore app.
    You can uninstall the GitHub Restore app after the recovery is complete or if it is no longer needed.

Results

RSC updates the granular permissions for the GitHub organization.

What to do next

After you install the apps, RSC creates resources in the background. Developer Collaboration backups can take up to 30 minutes to start. To protect pull requests and issues, assign an SLA Domain that has Developer Collaboration protection turned on. For more information, see Creating a custom SLA Domain for GitHub.
