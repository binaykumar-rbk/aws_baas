Deploying a Rubrik Cloud Cluster on GCP

Edit the customer details file and use that file to deploy a Rubrik Cloud Cluster ES on Google Cloud Platform.

Before you begin

Download the setup files from support.rubrik.com. Create a key for the service account to authenticate to the Rubrik Cloud Cluster Elastic Storage (Rubrik Cloud Cluster ES).

Procedure

  1. On a computer, navigate to the directory that contains the files obtained from support.rubrik.com, along with the private key file.
  2. Optional: To deploy a version of the image that matches Rubrik CDM version installed on the cluster, edit the base_node_image field.
    Note:
    When you are using the deployment script in preparation for adding the new nodes to an existing cluster, the version of the image must match the Rubrik CDM version installed on the cluster.
  3. Using a plain text editor, open customer_details.yml and fill in the fields.
  4. Save the file.
  5. Log in to the Google Cloud console.
  6. In the upper-right of the display, click the terminal icon to activate Cloud Shell.
  7. At the top of the console, open the three-dot menu and select Upload Files.
    The Rubrik base image folder opens and lists the files in that folder.
  8. Select all the files in the folder and click Open.
    A window appears and shows file transfer progress.
  9. In the Cloud Shell, grant execute permission to deploy_rubrik_cluster.py.
    Type chmod u+x deploy_rubrik_cluster.py.
  10. Run the command to deploy the cluster.
    Type ./deploy_rubrik_cluster.py --deployment_details_file customer_details.yml.
    The Cloud Shell displays information messages that indicate the progress of the deployment. After each node is deployed, the script displays the IP address for that node.
  11. Copy and retain the name and private IP address of each node.
    System setup requires these IP addresses.

Results

Google Cloud instantiates cluster nodes with the Rubrik base image, and deploys the nodes according to the instructions in the customer_details.yml file.

What to do next

SSH to one of the nodes and set up the cluster, as described in Setting up the Rubrik Cloud Cluster Elastic Storage on Google Cloud Platform.
