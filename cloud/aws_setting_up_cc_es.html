Setting up Rubrik Cloud Cluster Elastic Storage on Amazon Web Services

Use an SSH session to set up Rubrik Cloud Cluster Elastic Storage on Amazon Web Services.

Before you begin

Instantiate the nodes, as described in Instantiating the nodes for Rubrik Cloud Cluster Elastic Storage on Amazon Web Services.
In addition, gather the following information:
  • IP addresses for the nodes in the Rubrik Cloud Cluster Elastic Storage deployment

    The IP addresses are available on the Instances page in the EC2 dashboard.

  • Name of the .pem file that contains the SSH key
  • Amazon Resource Name (ARN) of the customer-managed KMS key that encrypts the cluster recovery package

Procedure

  1. Log in to a computer with access to the Rubrik Cloud Cluster Elastic Storage deployment and the SSH key pair.
  2. Use SSH to connect to one of the Rubrik Cloud Cluster Elastic Storage nodes.
    From a terminal prompt, enter: ssh -i path-to-pem-file admin@node-private-ip-address
    Where:
    • path-to-pem-file is the path to the file containing the SSH key.
    • node-private-ip-address is the private IP address of one of the Rubrik Cloud Cluster Elastic Storage nodes.
    The welcome message appears.
  3. At the prompt, enter network nslookup www.rubrik.com dns, where dns is the IP address of a DNS server that is available to Rubrik Cloud Cluster Elastic Storage.

    This command tests the connectivity between the Rubrik Cloud Cluster Elastic Storage node and the DNS servers.

    The system setup script uses Google DNS at 8.8.8.8 as the default value.

    If the network nslookup request fails to access www.rubrik.com, replace dns with the IP address of a DNS server that is available to Rubrik Cloud Cluster Elastic Storage.

  4. Repeat the connectivity test for each DNS server used by Rubrik Cloud Cluster Elastic Storage.
  5. At the prompt, enter network ping ntp, where ntp is the IP address of the NTP server available to Rubrik Cloud Cluster Elastic Storage.

    The system setup script uses the NTP Project server pool at pool.ntp.org as the default value.

    If the ping command fails, replace ntp with the IP address of an NTP server that is available to Rubrik Cloud Cluster Elastic Storage.

  6. Repeat the network ping test for each NTP server used by Rubrik Cloud Cluster Elastic Storage.
  7. At the prompt, enter cluster bootstrap.
    The User configuration section appears.
  8. At E-mail, enter a valid email address.
    Rubrik Cloud Cluster Elastic Storage sends notifications and alerts to this email address.
  9. At Password, enter a secure password for the admin account.
    Keep the new password in a secure location. The password also provides web UI access for the admin account.
  10. At Re-enter Password, re-enter the password.
    The Cluster configuration section appears.
  11. At Cluster name, enter a name for Rubrik Cloud Cluster Elastic Storage.
    Rubrik Cloud Cluster Elastic Storage uses the name to identify itself in the Rubrik CDM web UI and with other Rubrik clusters.
  12. At DNS Nameservers, enter a comma-separated list of IP addresses of DNS servers.
    Alternatively, press Enter (Windows system) or return (Mac system) to accept the default DNS server, 8.8.8.8, which is the Google DNS server.
  13. Optional: At DNS Search Domains, enter a comma-separated list of search domains.
  14. At NTP Servers, enter a comma-separated list of NTP servers.
    Provide the FQDN or IP address of each NTP server.

    Alternatively, press Enter (Windows system) or return (Mac system) to accept the default value, pool.ntp.org. This is the virtual cluster of NTP servers that is provided for public use by the NTP Pool Project.

    An invalid NTP server configuration prevents the addition of vCenter servers, and Windows and Linux hosts.

    When the NTP server is invalid, the web UI displays a banner alert. When this alert appears, correct the NTP server configuration.

  15. At Use cloud storage (y/n), press Enter (Windows system) or return (Mac system) to answer yes.
  16. At S3 bucket name, enter the name of the S3 bucket that will store the data for Rubrik Cloud Cluster Elastic Storage.
  17. At Enable Immutable Storage? (y/n), press Enter (Windows system) or return (Mac system) to answer yes.
    This turns on immutability for Rubrik Cloud Cluster Elastic Storage.
  18. At KMS Key ARN, enter the ARN of the customer-managed KMS key for Rubrik to use to encrypt the cluster recovery package.
    For example, arn:aws:kms:{region}:{account-id}:key/{key-id}.
  19. At Management Gateway, enter the IP address of the management gateway to use.
    Alternatively, press Enter (Windows system) or return (Mac system) to accept the default value, which the cloud provider assigned to the nodes on the network.
  20. At Management Subnet Mask, enter the subnet mask of the management network.
    Alternatively, press Enter (Windows system) or return (Mac system) to accept the default subnet mask.
  21. At Number of nodes (1 or 3+), enter the number of AMI instances in Rubrik Cloud Cluster Elastic Storage.
    This number is the same as the number of AMI instances deployed from the AWS Marketplace.
  22. At Node 1 Management IP, enter the IP address for the first node in Rubrik Cloud Cluster Elastic Storage.

    The IP addresses are available in the Private IP Address field for the first AMI instance on the Instances page of the AWS management console.

    Enter the IP address correctly because you cannot change the IP addresses assigned to the Rubrik Cloud Cluster Elastic Storage nodes later.

    The script prompts for the IP address of the next node.
  23. At the prompt for each of the remaining nodes, enter the IP address for that node and press Enter (Windows system) or return (Mac system).
    After entering the last IP address, the JSON-formatted body of the setup request appears.
  24. At Proceed?, enter y.

Results

The Rubrik CLI starts the system setup process. The Bootstrap Progress section appears and the CLI displays progress messages. After the successful completion of the setup process, the Rubrik Cloud Cluster Elastic Storage deployment is ready to register.

What to do next

Choose a method to register Rubrik Cloud Cluster Elastic Storage, as described in Cluster registration.
