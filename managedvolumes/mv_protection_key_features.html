Key features for Managed Volumes and SLA Managed Volumes protection

RSC provides unified data management, automated global data protection, backup and recovery options, and advanced security features to protect critical data for Managed Volumes and SLA Managed Volumes.

RSC provides comprehensive features for protecting and managing Managed Volumes and SLA Managed Volumes.

Unified data management

The following table provides details about the unified data management features for Managed Volumes and SLA Managed Volumes.
Feature Supported in Description
RSC data protection RSC Provides a Software as a Service (SaaS) platform to manage and protect Managed Volumes and SLA Managed Volumes across multiple deployment environments.
Consolidated reporting and monitoring RSC Provides unified reporting to track SLA Domain assignments, protection and recovery activities, and SLA Domain policy compliance for Managed Volumes and SLA Managed Volumes.
Rubrik Cloud Cluster Elastic Storage (ES)
  • Microsoft Azure: Rubrik CDM versions 8.1 and later

Automated global data protection through SLA Domains

The following table provides details about the automated global data protection features for Managed Volumes and SLA Managed Volumes.
Feature Supported in Description
Protection policies RSC Assigns SLA Domains to Managed Volumes and SLA Managed Volumes to ensure backup operations meet defined business needs, Recovery Time Objectives (RTO), or Recovery Point Objectives (RPO) requirements.
Automated backups RSC Uses SLA Domains to automate backups of SLA Managed Volumes based on a defined schedule.
Pause and resume protection Rubrik CDM version 5.2 or later Enables administrators to temporarily pause or restart protection activities for all Managed volumes and SLA Managed Volumes across an entire Rubrik cluster or SLA Domain.
Object-level pause and resume Rubrik CDM version 9.5.1 or later Enables administrators to temporarily pause or resume scheduled backup, archiving, and replication for individual Managed Volumes and SLA Managed Volumes without affecting other protected objects. For more information, see Object-level pause and resume for Managed Volumes and SLA Managed Volumes.
Reset reason visibility Rubrik CDM version 9.5 or later Displays the reset reason on the Managed Volumes and SLA Managed Volumes pages when a Managed Volume or SLA Managed Volume encounters a reset condition. For Managed Volume and SLA Managed Volume resets, RSC also sends an email notification identifying the affected volume. For more information, see Managed Volumes and SLA Managed Volumes reset reasons.

Backup and recovery

The following table provides details about the backup and recovery features for Managed Volumes and SLA Managed Volumes.
Feature Supported in Description
On-demand snapshots Rubrik CDM version 5.2 or later Supports taking manual snapshots of Managed Volumes and SLA Managed Volumes as needed, outside predefined schedules.
Archiving Rubrik CDM version 5.2 or later Enables long-term retention of snapshots by tiering them to lower-cost archival storage, such as cloud object storage for compliance and cost efficiency.
Multiple archival locations Rubrik CDM versions 9.4 and later Supports multiple archival targets for a single Managed Volume and SLA Managed Volumes to enhance data redundancy and compliance.
Legal hold Rubrik CDM versions 7.2 and later Retains specific snapshots indefinitely for legal or compliance reasons, overriding standard SLA Domain expiration policies.
Replication Rubrik CDM version 5.2 or later Replicates snapshots to other Rubrik clusters for disaster recovery purposes.
Replication pair co-existence with archival reader Rubrik CDM version 9.4.0 or later Maintains an active archival connection for a cluster while simultaneously serving as a replication reader for another cluster.
Retention lock Rubrik CDM versions 7.2 and later Provides compliance and legal requirement mechanisms to enforce immutable retention periods for backups, preventing unauthorized deletion or modification of data.
Rubrik CDM Offline Recovery UI Rubrik CDM versions 9.3.0 and later Provides a modern user interface for network and volume configuration management during offline recoveries.
Cross SMB domain recovery RSC Provides flexibility for Live Mount recoveries by allowing distinct SMB details, including domain name, username, and Active Directory (AD) groups, when recovering to hosts configured with different SMB domains or user accounts.

Security and access control

The following table provides details about the security and access control features for Managed Volumes and SLA Managed Volumes.
Feature Supported in Description
RBAC RSC Provides administrators with granular permissions to manage data protection operations for Managed Volumes and SLA Managed Volumes.
Quorum authorization Rubrik CDM versions 9.3.1 and later Enforces authorized approvals to modify data protection decisions, such as policy changes and deletion requests, to prevent unauthorized actions and protect data integrity.
NFSv4 without TLS Rubrik CDM versions 9.3.0 and later Supports the NFS version 4 protocol for environments where NFSv3 is restricted for security reasons.
Note:
TLS encryption for data in transit is currently not supported for Managed Volumes and SLA Managed Volumes. For more information, see Rubrik Compatibility Matrix.
User notes RSC Enables you to add descriptive notes to Managed Volumes and SLA Managed Volumes objects for audit and tracking purposes.

Networking

The following table provides details about the networking features for Managed Volumes and SLA Managed Volumes.
Feature Supported in Description
VLAN support Rubrik CDM version 5.2 or later Supports explicit assignment of a subnet, in Classless Inter-Domain Routing (CIDR) format, to restrict network traffic of Managed Volumes or SLA Managed Volumes to a specific VLAN.
IPv6 support Rubrik CDM versions 9.0 and later Supports communication and protection over IPv6 networks.
NAT support for NFS-based SLA Managed Volumes Rubrik CDM version 9.5.1 or later Supports auto-discovery of the source IP address for hosts located behind a NAT device when using NFS-based SLA Managed Volumes. This ensures that the Rubrik cluster communicates with the correct IP address during backup and recovery operations, even when the network address of the host has been translated.
Note:
You must install the curl binary on the host machine to enable auto-discovery of the NAT IP address.
